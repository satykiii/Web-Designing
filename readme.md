# Eventify - Event Management Website

## About the Project

Eventify is a modern and responsive event management website
that allows users to explore upcoming events, view event details
and register for their favourite events.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git and GitHub

## Features

1. Responsive homepage
2. Upcoming event cards
3. Event search functionality
4. Category-based filtering
5. Event details popup
6. Registration form
7. JavaScript form validation
8. Registration confirmation
9. Dark and light mode
10. Event countdown timer
11. LocalStorage registration management

## Project Structure

Eventify/
- index.html
- style.css
- script.js
- README.md
- images/

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open index.html in your browser.
4. Explore and register for events.

## Deployment

The website can be deployed using:

- Netlify
- GitHub Pages
